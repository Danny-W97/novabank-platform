# Prompty grafik Control Center

Tryb: wbudowane imagegen. Wygenerowane przed implementacją, bez klucza API i bez fallbacku CLI. Obrazy są koncepcjami z przykładowymi danymi, nie screenshotami działającego środowiska.

## 01-dashboard

```text
Use case: ui-mockup. Asset type: high fidelity concept screenshot of a local operator web application, NOT a customer banking site. Create a flat front-facing widescreen desktop UI, no monitor frame. Name: "NovaBank Control Center". Polish typography, crisp readable labels, professional shipping-quality layout. Style inspired by light Alior mobile banking: warm off-white background #f6f3f0, white cards, burgundy #8b003a, restrained warm gold #c5a35c accents, dark charcoal text. Use an original simple NB monogram, NEVER an Alior logo, no people, no phones, no credit card details, no passwords or keys. Left white navigation with labels "Pulpit", "Operacje", "Testy i logi", "Dokumentacja". Header has DEV / TEST selector and small "PROD — tylko diagnostyka" badge. Generous spacing, rounded cards, clear hierarchy, subtle dividers. All service statuses are illustrative; visible small footer text exactly "Wizualizacja — dane przykładowe". Do not add AI chat or unrelated microservices. Screen: selected "Pulpit". Main title "Centrum operacyjne". Subtitle "Bank i sklep w jednym miejscu". Three summary cards "Aplikacje", "Infrastruktura", "Ostatnie zadanie". Main wide services table has six rows "NovaBank :8080", "NovaTech Shop :8081", "PostgreSQL bank :5300", "PostgreSQL sklep :5400", "Redis :6379", "Monitoring". Status pills mix "Dostępny" and "Nieaktywny". Right quick actions panel with "Sprawdź środowisko", "Uruchom DEV", "Testy jednostkowe", "Otwórz bank". Bottom compact recent activity table. Light theme throughout, burgundy selected sidebar and main action.
```
